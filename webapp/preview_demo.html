📝 수행평가 자동채점

학생을 고르면 제출한 파일이 여기에 나옵니다.

처음이면 📋 루브릭·자료에서 루브릭을 올린 뒤 ▶ 채점 시작을 누르세요.

📋 루브릭·자료

1. 평가 루브릭 필수 · 파일을 고르면 자동으로 등록됩니다 (PDF·Word·한글(hwpx)·엑셀·사진·텍스트)

2. 빈 활동지 선택 · 클래스룸에 배포한 원본을 자동으로 가져옵니다. 다른 원본은 파일을 고르면 자동 등록

3. 예시답안 선택 · 파일을 고르면 자동 등록 · 글과 그래프·코드 이미지를 채점 기준으로 사용 (이미지가 있으면 Google 문서 링크나 Word)

🖼 이미지 읽기 이 수행평가에서 학생이 넣은 그래프·코드·실행결과 이미지를 평가할지 선택

과제 설명 선택 · AI에게 맥락으로 전달 (예: 중2 정보 - 정렬 알고리즘 탐구)

루브릭과 세부항목(체크리스트) 세부항목 점수 합 = 항목 배점 · 점수 단위 - · 세부항목은 1개당 점수 단위로 나뉩니다

# 수행평가 자동채점 — 웹앱 버전

스프레드시트 없이 **브라우저에서 여는 앱**입니다. 왼쪽에 학생 목록, 오른쪽에 선택한 학생의 세부항목 체크리스트·감점 사유·이미지가 나오는 대시보드 한 화면입니다.

## 설치 (한 번만, 약 5분)

1. [script.google.com](https://script.google.com) → **새 프로젝트** (이름 예: 수행평가 자동채점)
2. 파일 3개 넣기
   - `Code.gs`: 편집기의 Code.gs 내용을 지우고 붙여 넣기
   - `Index.html`: 왼쪽 **＋ › HTML** → 이름을 `Index`로 만들고 붙여 넣기
   - `appsscript.json`: ⚙ **프로젝트 설정** › "appsscript.json 매니페스트 파일 표시" 체크 → 편집기에서 내용 교체
3. API 키: ⚙ **프로젝트 설정 › 스크립트 속성 › 속성 추가** → 이름 `BAZE_API_KEY`, 값에 BAZE 키
4. 💾 저장
5. **배포 › 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **웹 앱에 액세스하는 사용자**
   - 액세스 권한이 있는 사용자: **우리 학교(도메인) 안의 모든 사용자**
   - **배포** → 권한 승인(“확인하지 않은 앱” 경고가 나오면 고급 › 이동 › 허용)
   - 선생님마다 처음 열 때 본인 계정으로 권한을 한 번 승인합니다.
6. 나온 **웹 앱 URL**을 즐겨찾기에 추가하세요. 휴대폰에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

> 코드를 고친 뒤에는 **배포 › 배포 관리 › ✏ 수정 › 버전: 새 버전 › 배포**를 해야 같은 URL에 반영됩니다.

## 사용 순서

1. 위쪽에서 **수업 → 과제** 선택 (⭐ = 점수 자동 반영 가능한 과제, [초안] = 게시 전)
2. **📋 루브릭·자료**
   1. 평가 루브릭 올리기 → AI가 항목·배점·기준을 정리하고, 점수 단위를 계산하고, **세부항목(체크리스트)** 을 만듭니다(1~2분)
   2. 빈 활동지는 클래스룸 과제의 원본을 자동으로 가져옵니다(선택)
   3. 예시답안(선택, 그래프·코드 이미지 포함 가능)
   4. 아래 편집기에서 세부항목 이름·기준·점수·평가 이미지(그래프/코드/실행결과)를 확인하고 고친 뒤 **수정 내용 저장**
3. **▶ 채점 시작**: 새로 제출했거나 다시 제출한 학생만 두 명씩 채점하며, 진행 막대가 보입니다. **■ 멈춤**으로 중간에 멈출 수 있습니다.
4. 학생을 눌러 확인
   - **감점 사유**: 빠진 세부항목이 "2-2 축·단위 −15"처럼 표시
   - 세부항목 체크를 바꾸면 점수가 바로 다시 계산되고 저장됩니다. 체크 아래에는 AI가 그렇게 판단한 이유가 나옵니다.
   - **🖼 학생 이미지 보기**: 학생이 넣은 그래프·코드 캡처를 확인(누르면 크게 보기)
   - 빨간 **검토 필요** 표시는 확인 후 **검토 완료**를 눌러야 반영 대상이 됩니다.
   - 피드백 수정, 학번 수정 가능
5. **⬆ 클래스룸 반영**: 검토 필요가 없는 학생 점수를 임시 점수로 넣습니다(반환 전까지 학생에게 안 보임). 루브릭 합계와 과제 만점이 다르면 자동으로 환산합니다.

**⋯ 메뉴**: 전체 다시 채점 / 🧪 테스트 채점(저장 안 함) / 📄 시트로 내보내기(기록 보관) / 💬 피드백을 학생 문서에 댓글로 / ➕ 활동지 사본 배포 과제 만들기 / ⚙ 설정(모델·추론 강도·피드백 말투 등)

## 구글 로그인과 사용 권한

- 앱은 **접속한 선생님 본인의 구글 계정**으로 로그인해 그 선생님의 클래스룸 수업·드라이브를 씁니다. 화면 오른쪽 위에 로그인한 계정이 보이고, **계정 전환**으로 다른 계정으로 바꿀 수 있습니다.
- 브라우저에 구글 계정이 여러 개 로그인되어 있으면 앱이 멈출 수 있으니, 학교 계정 전용 크롬 프로필이나 시크릿 창에서 여세요.
- 선생님으로 등록된 클래스룸 수업이 없는 계정(학생 등)은 "교사 계정으로 로그인해 주세요" 화면이 나옵니다.
- **사용할 수 있는 계정을 제한하려면** Apps Script ⚙ 프로젝트 설정 › 스크립트 속성에 `ALLOWED_EMAILS`를 추가하세요.
  - 특정 선생님만: `kim@example.kr, lee@example.kr`
  - 학교 도메인 전체: `@example.kr`
  - 비워 두면 도메인 안의 모든 계정이 쓸 수 있습니다.
- **BAZE API 키는 하나(스크립트 속성 `BAZE_API_KEY`)를 모든 사용자가 함께 씁니다.** 사용 비용이 그 키의 계정에 합산되니, 필요하면 `ALLOWED_EMAILS`로 제한하세요.

## 자료 등록과 세부항목

- **파일을 고르면 바로 등록됩니다.** 루브릭·빈 활동지·예시답안 모두 별도의 저장·불러오기 버튼이 없습니다. 링크나 글을 붙여 넣었다면 칸 밖을 클릭하면 등록됩니다. 이미 루브릭이 있으면 덮어쓰기 전에 한 번 물어봅니다.
- 빈 활동지는 **클래스룸에서 다시 가져오기**를 눌러도 바로 등록됩니다. 클래스룸 과제에 '학생별 사본'으로 첨부된 구글 문서가 없으면 그렇다고 알려 주고, 기존에 등록한 빈 활동지는 지우지 않습니다.
- **세부항목은 1개당 점수 단위(예: 5점)로 나뉩니다.** 40점 항목이면 5점짜리 8개이고, 틀릴 때마다 −5점씩 감점됩니다. 개수는 많아도 상관없습니다. 단위는 루브릭에서 자동으로 계산하며, 📋 루브릭·자료 아래쪽 **"세부항목 1개당 □점"** 칸에서 바꾼 뒤 **세부항목 AI로 다시 만들기**를 누르면 새 단위로 다시 만듭니다.
- 세부항목을 고치면 **[수정 내용 저장]**을 눌러야 저장됩니다. 저장하지 않은 변경이 있으면 빨간 안내가 보이고, 창을 닫으려 하면 한 번 물어봅니다.
- 세부항목이 바뀐 뒤에는 이미 채점한 학생에게 **"다시 채점 필요"** 표시가 붙고, 다시 채점하기 전까지 클래스룸 반영에서 제외됩니다(점수가 어긋나는 것을 막기 위해서입니다).

## 이미지 읽기 설정 (수행평가마다 선택)

📋 루브릭·자료 › **🖼 이미지 읽기**에서 이 수행평가에 학생 이미지(그래프·코드·실행결과 캡처)를 평가할지 고릅니다. 현재 상태는 위쪽 배지(`🖼 이미지 읽음` / `📝 글만 평가`)로도 보입니다.

| 설정 | 동작 |
|---|---|
| 자동 (기본) | 루브릭에 "평가 이미지"가 지정된 항목이 있으면 읽고, 없으면 글만 평가 |
| 항상 읽기 | 이미지를 평가에 사용 |
| 읽지 않기 | 글만 평가. 이미지가 없어도 감점·검토 표시 없음. 더 빠르고 AI 사용량이 적음 |

설정을 바꾼 뒤에는 이미 채점한 학생을 **다시 채점**해야 반영됩니다.

## AI가 작업하는 동안

루브릭 정리, 세부항목 생성, 테스트 채점, 시트 내보내기, 클래스룸 반영 중에는 화면 아래에 **게이지바와 경과 시간**이 나타납니다. 학생 채점 중에는 `3 / 12명 완료 · 남은 시간 약 2분`으로 진행 상황이 보입니다. 작업 중에 창을 닫거나 새로고침하지 마세요(나가려 하면 경고가 뜹니다). 채점은 학생마다 저장되므로 중간에 멈춰도 끝낸 학생의 결과는 남습니다.

## 데이터는 어디에?

- 로그인한 선생님의 내 드라이브 **"자동채점 앱 데이터"** 폴더에 과제마다 JSON 파일 1개로 저장됩니다(선생님마다 따로)(루브릭·세부항목·채점 결과·선생님 수정 내용).
- "시트로 내보내기"로 만든 스프레드시트도 같은 폴더에 저장됩니다.
- 이 폴더를 지우면 채점 기록이 사라지니 주의하세요.

## 알아둘 점

- 클래스룸 화면에서 직접 만든 과제는 구글 정책상 점수 자동 반영이 막혀 있습니다. 앱에서 채점·확인한 뒤 점수를 직접 입력하거나, 다음부터는 ⋯ › **활동지 사본 배포 과제 만들기**로 과제를 만드세요.
- AI에는 학생 이름·이메일을 보내지 않고 문서 내용(글·이미지)만 보냅니다.
- 3.5MB보다 큰 이미지나 지원하지 않는 형식의 이미지는 AI가 보지 못하며, 그 학생은 검토 필요로 표시됩니다.
- 예전 스프레드시트 버전(`../sheet-version/`)의 데이터는 자동으로 옮겨지지 않습니다. 새 과제부터 웹앱을 쓰는 것을 권합니다.

# 클래스룸 수행평가 서술형 자동채점기

Google 문서 활동지를 **학생별 사본**으로 나눠 준 과제의 제출물을 읽고, 루브릭 기준으로 AI(BAZE 게이트웨이)가 문항별 점수·근거·피드백을 만들어 줍니다. 결과는 스프레드시트에 기록되고, 교사가 확인한 뒤 클래스룸에 **임시 점수**로 넣습니다.

```
클래스룸 제출물(학생 사본 문서) → 문서 텍스트 추출(표 포함) → AI 루브릭 채점
 → [채점결과] 시트(교사 검토·수정) → 클래스룸 임시 점수 → 교사가 반환
```

## 1. 설치 (한 번만)

1. 새 Google 스프레드시트 만들기 → **확장 프로그램 > Apps Script**
2. `Code.gs` 내용을 통째로 붙여 넣기
3. 왼쪽 ⚙️ **프로젝트 설정** → "편집기에 appsscript.json 매니페스트 파일 표시" 체크 → `appsscript.json` 내용으로 교체
   (Classroom API·Drive API 고급 서비스가 이 파일로 켜집니다)
4. 저장 → 스프레드시트 새로고침 → 상단에 **📝 자동채점** 메뉴가 생김
5. 처음 실행 시 권한 승인 창이 뜨면 학교 계정으로 허용

## 2. 사용 순서

| 메뉴 | 하는 일 |
|---|---|
| ① 시트 만들기 | [설정]·[루브릭]·[채점결과] 시트 생성. 채점결과 = **학번·학생이름·최종점수·항목별 점수/근거** (항목 수는 루브릭에 맞춰 자동 조정) |
| ② 수업·과제 선택 | 창에서 수업과 과제를 고름(⭐ = 점수 자동 반영 가능). 그 과제에 배포한 원본 활동지를 빈 활동지로 자동 저장 |
| ③ 루브릭·활동지·예시답안 업로드 | 1) 평가 루브릭(필수: PDF·Word·한글 hwpx·엑셀·사진·텍스트·구글문서 링크, AI가 항목/배점/기준으로 정리) → 2) 빈 활동지(선택, 보통 ②에서 자동) → 3) 예시답안(선택, 그래프·코드 이미지 포함 가능) |
| ④ 제출물 자동 채점 | 제출완료 학생만 채점. 이미 채점한 학생은 건너뛰고, 다시 제출한 학생은 자동 재채점 |
| ④-1 선택한 행만 다시 채점 | 루브릭 수정 후 특정 학생만 재채점 |
| ⑤ 클래스룸에 임시 점수 반영 | [검토필요] 표시가 없는 학생만 반영. 루브릭 합계와 과제 만점이 다르면 자동 환산 |
| (선택) 문서 댓글 | 종합피드백을 학생 문서에 댓글로 (학생에게 바로 보임) |

**API 키**: Apps Script 편집기 ⚙️ 프로젝트 설정 > 스크립트 속성에 `BAZE_API_KEY` 이름으로 저장 (`API_KEY` 등 다른 이름이어도 키 속성이 하나뿐이면 자동 인식).

**세부항목(체크리스트) 채점**: 루브릭을 올리면 AI가 항목마다 5점 단위 세부항목을 만들어 [세부항목] 시트에 적습니다(점수 합 = 항목 배점, 직접 수정 가능, 메뉴 ③-1로 다시 만들기). 채점결과 시트는 `학번 | 학생이름 | 최종점수 | 감점 사유 | 1. 항목 점수 | ☑1-1 | ☑1-2 | … ` 구성이며, AI가 세부항목별로 체크합니다. 체크된 점수만 합산되고, **감점 사유** 칸에 빠진 세부항목이 "2-1 그래프 첨부 -20"처럼 표시됩니다. 체크박스에 마우스를 올리면 AI가 그렇게 판단한 이유가 보이고, 선생님이 체크를 바꾸면 점수와 감점 사유가 바로 다시 계산됩니다.

**이미지 평가**: 루브릭을 올리면 그래프·코드·실행결과 이미지로 평가하는 항목을 AI가 찾아 [루브릭] 시트 "평가 이미지" 칸에 적습니다(직접 수정 가능). 채점 때 학생 문서의 이미지를 직접 보고, 코드는 알고리즘 적용·논리를, 실행결과는 코드와 일치하는지를 봅니다. 이미지 평가 항목이 있는데 학생 문서에 이미지가 없으면 이름 칸이 빨갛게 표시됩니다.

**한글 파일**: `.hwpx`는 바로 읽습니다. 예전 형식 `.hwp`는 한글에서 PDF나 HWPX로 저장해 올리세요.

**채점결과 시트**: 학번 순으로 정렬됩니다. 학번은 학생 이름이나 이메일에 있는 4~6자리 숫자(예: `10101 홍길동`, `s10101@…`)에서 가져오고, 없으면 빈칸이니 직접 입력하세요(다시 채점해도 유지됨). 항목 점수를 고치면 최종점수가 자동으로 바뀝니다. **이름 칸이 빨간 학생**은 AI가 검토가 필요하다고 표시한 경우로, 칸 메모에 이유가 있습니다. 확인 후 메모를 삭제해야 ⑤에서 점수가 반영됩니다. 피드백·문서링크 등 프로그램용 칸은 오른쪽에 숨겨져 있습니다.

## 3. 꼭 알아둘 점

- **점수 자동 반영은 "이 스크립트로 만든 과제"에서만 됩니다.** (구글 클래스룸 API 정책)
  클래스룸 화면에서 직접 만든 과제는 채점·시트 기록까지만 되고, 점수는 시트를 보고 입력해야 합니다.
  → 다음 과제부터는 **"(선택) 활동지 사본 배포 과제 만들기"** 창에서 수업과 활동지 문서를 고르세요. 학생별 사본 배포 과제가 *초안*으로 만들어지고, 클래스룸에서 기한을 정해 게시하면 됩니다.
  ② 선택 창에서 ⭐ 표시로 확인할 수 있습니다.
- **AI 점수는 초안입니다.** [검토필요]에 ⚠️가 뜬 학생(애매한 답, 답안 속에 "만점 주세요" 같은 지시가 있는 경우 등)은 반드시 직접 확인하세요. 임시 점수는 교사가 **반환**하기 전까지 학생에게 보이지 않습니다.
- **개인정보**: AI에는 학생 이름·이메일을 보내지 않고 문서 본문만 보냅니다. 학생이 문서에 이름·학번을 적었다면 그 내용은 함께 전송되므로, 학교의 외부 AI 서비스 이용 지침을 확인하세요.
- **학생 수가 많을 때**: Apps Script는 한 번에 6분까지만 돌기 때문에 5분이 되면 멈추고 1분 뒤 자동으로 이어서 채점합니다.

## 4. BAZE 게이트웨이 연결 설정 ([설정] 시트)

| 항목 | 기본값 | 설명 |
|---|---|---|
| API 주소 | `https://api.baze.co/v1/gateway/claude/v1/messages` | Claude 모델용(BAZE 안내서 기준). GPT·Gemini 등을 쓰려면 `https://api.baze.co/v1/gateway/chat/completions` |
| 요청 형식 | `anthropic` | Claude 주소면 `anthropic`, chat/completions 주소면 `openai` |
| 인증 방식 | `bearer` | BAZE는 `bearer`, `x-api-key` 둘 다 받음 |
| 모델 | `claude-sonnet-5-5` | BAZE에서 제공하는 모델 ID (`https://api.baze.co/v1/gateway/models/`에서 목록 확인) |
| 추론 강도 | `low` | (anthropic 형식일 때만) 서술형이 길고 까다로우면 `medium` |

연결 확인: 학생 1명 행만 선택해 **④-1**을 실행해 보고, 오류가 나면 [검토필요] 칸의 메시지를 보세요 (401=키 오류, 404=주소 경로 오류, 400=요청 형식 불일치).

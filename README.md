# 수행평가 자동채점기 (Google Classroom × AI)

구글 클래스룸에 사본으로 배포한 서술형 수행평가 활동지를, **루브릭 세부항목(체크리스트)** 기준으로 AI가 채점하고 선생님이 확인·수정한 뒤 클래스룸에 임시 점수로 반영하는 도구입니다. 학생이 넣은 **그래프·코드·실행결과 이미지**도 함께 평가합니다.

| 폴더 | 설명 |
|---|---|
| [`webapp/`](webapp/) | **웹앱 버전 (권장)**. 왼쪽 학생 목록 · 가운데 제출 문서 · 오른쪽 세부항목 체크 채점. 구글 로그인으로 사용 |
| [`sheet-version/`](sheet-version/) | 구글 스프레드시트에 붙여 쓰는 버전 (초기 버전) |

## 주요 기능
- 루브릭(PDF·Word·한글 hwpx·엑셀·사진·구글 문서)을 올리면 AI가 항목·배점·**세부항목 체크리스트**로 정리
- 체크된 세부항목 점수만 합산, **감점 사유**를 "2-2 삭제 함수 구현 −10"처럼 한눈에 표시
- 세부항목 체크를 바꾸면 점수 즉시 재계산, AI가 그렇게 판단한 이유 확인
- 빈 활동지·모범답안(이미지 포함)을 기준 자료로 사용, 채점 조작 문장·이미지 누락 학생은 자동으로 검토 필요 표시
- 클래스룸 임시 점수 반영, 시트 내보내기, 피드백 문서 댓글

## 빠른 시작
`webapp/README.md`의 설치 순서를 따르세요 (Apps Script 프로젝트에 파일 3개를 넣고 웹 앱으로 배포).
AI 호출은 BAZE 게이트웨이를 사용하며, **API 키는 코드에 넣지 않고** Apps Script 스크립트 속성 `BAZE_API_KEY`에 저장합니다.

## 주의
- 학생 답안이 외부 AI 서비스로 전송되므로 학교의 개인정보·AI 이용 지침을 확인하고 사용하세요(학생 이름·이메일은 보내지 않고 문서 내용만 전송).
- AI 점수는 **초안**입니다. 검토 필요 표시와 최종 점수는 반드시 교사가 확인하세요.
- 클래스룸 화면에서 직접 만든 과제는 구글 정책상 점수를 API로 넣을 수 없습니다(이 도구로 만든 과제만 자동 반영).
